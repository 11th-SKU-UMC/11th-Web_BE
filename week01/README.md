## ERD 설계 설명

IA와 와이어프레임을 바탕으로 회원, 지역, 음식 카테고리, 가게, 미션, 회원 미션 테이블을 구성하고, 각 테이블을 FK를 이용한 1:N 비식별 관계로 연결했습니다.

회원별 미션 수행 내역과 반복 도전을 관리할 수 있도록 회원 미션 ID를 별도의 PK로 설정했습니다. 또한 PASS 가능 항목으로 지도 및 검색, 포인트 관리, 알림 설정, 사장님의 점포 관리 기능을 추가로 설계했습니다.

가게의 위치를 표시하기 위해 위도와 경도를 추가하고, 포인트 적립 및 사용 내역을 관리하는 포인트 내역 테이블과 회원별 알림 수신 여부를 관리하는 알림 설정 테이블을 추가했습니다. 또한 사장님과 가게를 1:N 관계로 연결하여 한 명의 사장님이 여러 가게를 관리할 수 있도록 구성했습니다.
