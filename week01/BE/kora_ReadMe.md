## erd 설명
- IA와 와이어프레임의 필수 요구사항을 기준으로 저장해야 할 데이터 분석

- 회원, 지역, 가게, 음식 카테고리, 미션을 각각 독립적인 엔티티로 분리

- 회원과 미션 사이에 N 관계가 발생하는 것을 확인하고 `member_mission` 중간 매핑 테이블 구성

- 회원의 소셜 로그인 정보를 `social_account`로 분리하여 회원과 1 관계 구성

- 가게는 하나의 지역과 하나의 음식 카테고리에 속하도록 `region_id`, `food_category_id` FK 설정

- 가게 하나에서 여러 미션을 제공할 수 있도록 `store 1:N mission` 관계 구성

- 회원 탈퇴 시 데이터를 즉시 삭제하지 않도록 `member.deleted_at`을 추가하여 Soft Delete 고려

- 모든 PK는 `BIGINT AUTO_INCREMENT` 방식으로 통일

- 지도, 검색, 포인트 관리, 알림, 사장님 점포 관리 기능은 이번 미션의 설계 제외 대상이므로 ERD에서 제외
